# xiray

个人博客。纯手写 HTML / CSS，无框架、无构建、无外部依赖，托管于 GitHub Pages。

## 目录结构

```
blog/
├── index.html          首页（搜索 + 类别筛选 + 文章列表）
├── about.html          关于页
├── assets/
│   ├── style.css       全站样式
│   └── search.js       首页搜索与筛选
├── posts/              文章（生成物，别手改）
├── files/              附件
├── categories.json     类别列表
├── search-index.json   搜索索引（自动生成）
├── tools/              本地写作台（本机运行，不参与线上访问）
│   ├── 写作台.bat       双击启动
│   ├── writer.html     写作界面
│   ├── ai.html         AI 问答页
│   ├── publish.py      本地服务
│   └── sources/        每篇文章的编辑源（唯一真源）
├── .nojekyll
└── README.md
```

## 用写作台（推荐）

双击 `tools/写作台.bat`，浏览器自动打开 `http://127.0.0.1:5178`。

### 两种写作模式

顶部可切换，**内容可以随时互转**：

| 富文本 | Markdown |
| --- | --- |
| 选中文字点工具栏，所见即所得 | 左边写、右边实时预览 |
| 粗体 / 斜体 / 下划线 / 删除线 | `**粗体**` `*斜体*` `<u>下划线</u>` `~~删除~~` |
| 段落格式：正文 / 标题 / 小标题 / 更小标题 / 引用 / 代码块 | `#` `##` `###` `>` 三反引号 |
| 文字颜色、背景色 | 转成内联 `<span style="...">` 保留 |
| 表格、附件、图片、链接、列表、分割线 | 管道表格、HTML 附件标签、`![]()`、`[]()` |

颜色和附件在 Markdown 里以原始 HTML 片段存在，所以**来回切换不会丢样式**。

### 引用块和代码块怎么删

这两类块在浏览器里有个坑：内容删光后空框还留着，按退格也没反应。现在接管了：

- **块里内容删光后按退格** → 空框消失，留下一个空段落
- **光标在块的最前面按退格** → 取消块的格式，文字原样保留（不会并进上一段、也不会带出一堆内联样式）
- **引用块有多个段落时** → 只删掉当前这个空段落，不影响其它段落
- **代码块里按回车** → 正常换行，不会把结构拆坏

### 发布 / 编辑 / 删除

- 点「发布」→ 生成文章、更新首页列表、更新搜索索引、提交推送，30 秒后线上生效
- **发布时会显示当前进度**：生成 → 提交 → 推送第几次，后面跟着已用秒数。卡住的时候能一眼看出是卡在本地提交还是卡在推送上
- 推送失败不会丢内容：本地已经提交好了，网络恢复后再点一次发布即可（不会产生重复文章）
- 等超过 4 分钟会自动停止等待并提示
- **左侧就是文章列表**：点一条可直接编辑，鼠标移上去出现 ✕ 可以删除
- 编辑已发布的文章再点发布，是更新而不是新建

### 类别

字段区有类别下拉，选「＋ 新建类别…」可以随时加自定义类别。类别会显示在首页每条文章右边，也能用来筛选。

### 附件和图片

工具栏的回形针上传文件到 `files/`，文章里显示成可下载的卡片；图片格式直接插入为图片。

**图片会自动压缩**：长边超过 1600px 的缩到 1600，JPEG/WebP 按质量 82 重压，手机照片的方向也会自动校正。上传完状态栏会告诉你「压缩 3.2 MB → 420 KB」。小于 120KB 的图、GIF 动图、SVG 都不动。

## AI 问答

写作台顶栏的「AI 问答」按钮打开 `http://127.0.0.1:5178/ai`，也可以直接开这个地址。

**第一次用要配三样东西**（点右上角「设置」）：

| 项 | 填什么 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com`（别的 OpenAI 兼容服务也行） |
| 模型 | 先填地址和 Key，点「拉取模型列表」拿到准确名字再选，别猜 |
| API Key | 在服务商控制台生成，粘进来点保存 |

**Key 只存在本机。** 写在 `tools/.ai-config.json`（已加进 `.gitignore`，不会提交、不会推到线上），页面只能拿到打码后的 `sk-***abcd`，真正的请求由本地服务代发，浏览器里拿不到明文。

聊天页会流式显示回答、支持停止、回答可一键复制、代码块单独带复制按钮，对话存在浏览器本地，关掉再打开还在。用推理类模型时「思考过程」会折叠显示。

网络这里也做了自适应：先直连，不通再走系统代理，最后才自动探测本地代理端口；指向 `127.0.0.1` 的自建服务强制直连。出错时给的是人话——401 说 Key 无效，402 说余额不足，502 说代理没连上目标。

## 网页端搜索

首页搜索框支持：

- **关键词**：同时匹配标题、摘要、类别、正文全文
- **类别**：下拉筛选
- **日期范围**：起止日期
- 快捷键 `/` 聚焦搜索框，`Esc` 清空

搜索索引 `search-index.json` 在每次发布时自动重建，而且是**按需加载**——首屏不下载它，只有第一次输入关键词时才去取。类别和日期筛选直接读页面内容，不依赖这个文件。

首页文章按年份分组显示，每年一个小标题（`2026 · 4 篇`）。筛选时如果某一年一条都不剩，那一年的标题也会自动隐藏。

## 命令行

```bash
python tools/publish.py --sync      # 手动改完文件后：探测代理 → 提交 → 推送
python tools/publish.py --rebuild   # 重建首页列表与搜索索引
```

### 代理是自动的

每次推送前自己找代理：环境变量 → Windows 系统代理 → 常见本地端口（7897 / 7890 / 10809 / 64836 …），然后真的去连一次 `github.com`，谁能通就用谁，都不通就直连。

结果只作用于当次 git 命令，**不写进 `.git/config`**，代理换端口不用改任何东西。

## 注意

- **所有链接都是相对路径。** 项目页部署在 `/blog/` 子路径下，`/` 开头会 404。
- **不要手动改 `posts/` 里的文件。** 它们由 `tools/sources/` 生成，下次发布会被覆盖。
- **不要删 `.nojekyll`。** 删了之后下划线开头的文件会被 Jekyll 吞掉。
- **`tools/` 只在本机用。** 发布接口只监听 `127.0.0.1`，外网访问不到。
- **`tools/ai.html` 会跟着推到仓库**，但线上没有后端，打开只会提示连不上本地服务；能用的是本机那个地址。
- **API Key 永远不进仓库**：`tools/.ai-config.json` 已在 `.gitignore` 里，别把它挪到别的地方，也别贴进文章或截图。
- **写作台只能开一个。** 重复启动会检测到已经在跑，直接帮你打开浏览器并退出，不会再起一个抢端口。
- **提交时只跟踪站点相关路径**（`index.html`、`posts/`、`assets/`、`tools/` 等），放在仓库里的临时文件不会被 `git add -A` 顺手提交。

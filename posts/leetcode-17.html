LeetCode 17 电话号码的字母组合：我踩过的几个递归坑

2026 · 10 · 23 · 代码编写 · 约 2 分钟

1.重复枚举

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合

因为电话号码的位数不确定，所以正常的循环嵌套不能使用，需要用递归：先枚举第一位，再调用函数本身枚举第2位，以此类推。

结构为：
f(str, i)   i < n ?    true:     f(str, i + 1)
                       false:    return

但是每次枚举完，本轮的上一个答案因为没有删除字符串的末尾，所以会造成多个字母的连接，导致WA，所以每次枚举完需要pop_back 掉枚举出来的字符串的最后一位，保证枚举的结果不重叠。

2.类型错误

判定电话号码的第几位不能直接使用，因为他的格式是char，转换为int会导致索引出错，如字符'1'的ASCII编码为49，而实际使用的应为1。因为连个字符之间可以直接相减得到对应的编码，且0~9的编码是连续的，所以可以令int a = '1' - '0'，把char类型的数字转为int类型。

(int)'1' = 49
(int)'0' = 48
'1' - '0' =1
所以可建立函数：
int to_int(char a) {
  if(a >= '0' && a < = '9') return a - '0';
}

输入： '7'
输出：7      '7' - '0' = 55 - 48 = 7

3.总结

这道题我主要使用递归的方法实现，枚举每位字母，实现方法如下：

#include<bits/stdc++.h>
using namespace std;
class Solution {
public:
    vector<string> ans;
    string now_fixing;
    string a[10] = {"no", "no", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
    void sol(string & str, int i) {
        if(i == str.size()) {
            ans.push_back(now_fixing);
            return;
        }
        for(char chr : a[str[i] - '0']) {
            now_fixing += chr;
            sol(str, i + 1);
            now_fixing.pop_back();
        }
    }
    vector<string> letterCombinations(string digits) {
        sol(digits, 0);
        return ans;
    }
};

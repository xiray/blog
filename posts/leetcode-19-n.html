LeetCode 19 删除链表的倒数第 N 个结点：快慢指针法与哑节点边界处理

2026 · 10 · 24 · 代码编写 · 约 4 分钟

删除链表的倒数第 n 个结点

整体思路

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

解题方法：快慢指针 + 哑节点（dummy node）

快慢指针

因为链表的节点结构为 int val; ListNode *next;，只能正向遍历，无法直接找到倒数第几个节点，需要通过两个距相差 n 个节点的两个指针（fast 和 slow）来实现。先让 fast 运动 n 个节点，然后两个指针一起运动，直到 fast 到达链表最后一个节点（fast->next == nullptr），即 slow 到达倒数第 n+1 个节点。

修改链表指针

将 slow 所在节点的 next 跳过待删除节点（倒数第 n 个节点），直接链接到被删节点的下一个节点，即倒数第 n-1 个节点：

    slow -> next = slow -> next -> next; 
       ↑       ↑                     ↑
    倒数n+1  倒数n                  倒数n-1

（倒数序号越小越靠后）

哑节点（dummy head）

dummy 的主要作用，是把“删除头节点”这个特殊情况，变成“删除普通节点”。通过在头节点前面加一个节点，让原头节点不再是整个链表的第一个节点，方便处理删头操作。

关于 n 超出链表长度的情况：题目保证 n 合法，所以代码里不做判定。

完整代码

 struct ListNode {
  int val;
   ListNode *next;
   ListNode() : val(0), next(nullptr) {}
   ListNode(int x) : val(x), next(nullptr) {}
   ListNode(int x, ListNode *next) : val(x), next(next) {} 
  };

class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode *false_head = new ListNode(0, head);
        ListNode *fast = false_head , *slow = false_head;
        for(int i = 1; i <= n; i++) fast = fast -> next;
        while(fast -> next != nullptr) {
          fast = fast -> next;
          slow = slow -> next;
        }
        slow -> next= slow -> next -> next;
        return false_head -> next;
    }
};

LeetCode 42 接雨水：我的解题思路和踩过的坑

2026 · 10 · 27 · 代码编写 · 约 3 分钟

解题思路

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

这道题和leetcode11 盛最多水的容器很像，但是水不能漫过柱子，所以要依次计算每一部分水的大小。

两种算法

1. 依次计算每一层的水

这种解法的思路是把水也看成实心的，将每一层的大小相加，再减去柱子的大小，时间复杂度为 O(n * h), h 为柱子的最大高度，小数据能过，但是大数据会TLE。

2.依次计算横坐标上每一列的高度

这种解法与上一种相反，是竖着计算的，依次计算每一层的水。需要依次查看横坐标上每格水的高度。公式为：本格水 = min(左边最高的，右边最高的) - 本格竹子的高度。时间复杂度为 O(n)。

预处理操作

本来我是每次到一个新的柱子是都需要用双指针遍历来确定两边最高的柱子，结果TLE了，所以这道题需要提前处理最大数据，避免重复寻找，浪费时间。
思路：开始时定义两个数组，分别表示每一格两边最高的柱子，赋值时先把两个顶点的赋值，然后再比较柱子的高度和上一个最大值。代码如下：

int len = height.size();

vector<int> leftmax(len), rightmax(len);
//左边最大
leftmax[0] = height[0];
for (int i = 1; i < len; i++) leftmax[i] = max(leftmax[i - 1], height[i]);
//右边最大
rightmax[len - 1] = height[len - 1];
for (int i = len - 2; i >= 0; i--) rightmax[i] = max(rightmax[i + 1], height[i]);

总结

这道题我使用法2解决，代码如下：

#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
  int trap(vector<int> &height) {
    int len = height.size();
    int water = 0;

    vector<int> leftmax(len), rightmax(len);

    leftmax[0] = height[0];
    for (int i = 1; i < len; i++) leftmax[i] = max(leftmax[i - 1], height[i]);

    rightmax[len - 1] = height[len - 1];
    for (int i = len - 2; i >= 0; i--) rightmax[i] = max(rightmax[i + 1], height[i]);

    for (int i = 0; i < len; i++)
      water += min(leftmax[i], rightmax[i]) - height[i];

    return water;
  }
};

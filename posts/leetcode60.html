Leetcode60：排列序列我的思路与总结

2026 · 11 · 14 · 代码编写 · 约 4 分钟

整体思路

给出集合 [1,2,3,...,n]，其所有元素共有 n! 种排列。给定 n 和 k，返回第 k 个排列。

这题需要对全排列进行排序，但是不用枚举求出每个数列，会TLE，可以用康托展开的逆运算（由序号反推排列）直接求出第 k 个排列。

一句话说清康托分块：把所有排列按「第一位是谁」分成 n 组，每组大小是 (n-1)!。想知道第 k 个排列首位选几，只要算 k / (n-1)! 就知道落在第几组；算 k % (n-1)! 就得到组内偏移，再拿这个偏移去定第二位……如此逐位缩小，就能把答案「除」出来，不必真的枚举。

比如 n=3, k=3（1-based，转 0-based 得 k=2）：

  • 首位：block = 2! = 2，idx = 2/2 = 1 → 候选池 [1,2,3] 里第 1 个（0-based）是 2，剩 k = 0；
  • 第二位：block = 1! = 1，idx = 0 → 池 [1,3] 取 1；
  • 第三位：只剩 3。
  • 结果 213，正是 123, 132, 213 中的第三个。

解题方法

函数每次计算当前数位应填的数字，选择后从候选池中删除。

#include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    //定义阶乘函数
    long long fac(int n) {
      long long res = 1;
      for (int i = 1; i <= n; i++) res *= i;
      return res;
    }

    string ans;
    vector<int> nums;

    void sol(int pos, int n, int k) {
      //如果选够了就返回
      if (pos == n)
        return;

      //计算后面块的可能情况数量
      int remain = n - pos;
      long long block = fac(remain - 1);
      int idx = k / block;
      k %= block;
      
      ans += to_string(nums[idx]);
      nums.erase(nums.begin() + idx);
      sol(pos + 1, n, k);
    }

    //主函数
    string getPermutation(int n, int k) {
        ans.clear();
        nums.clear();
        for (int i = 1; i <= n; i++) nums.push_back(i);
        sol(0, n, k - 1);
        return ans;
    }
};

变量速查

一句话理解：nums 决定选谁，block 决定每块多大，idx = k / block 决定选第几个，k %= block 得到块内偏移，ans 攒出答案。

变量类型作用关键点
ansstring最终排列结果逐位 += 数字字符；每次调用前 clear()
numsvector<int>候选数字池（未使用）初始 [1..n]，始终保持升序；选一个删一个
pos / remainint当前填第几位（0-based）/ 还剩几位remain = n - pos，等于 nums.size()；pos == n 终止
blocklong long每块大小 = (remain-1)!固定当前位后，后面能产生的排列数
idxint当前位选池中第几个（0-based）idx = k / block，范围 [0, remain)
kint0-based 偏移量最外层传 k-1；递归中更新为 k % block

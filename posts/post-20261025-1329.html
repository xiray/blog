LeetCode 24 两两交换链表中的节点：哨兵节点 + 改 next 指针

2026 · 10 · 25 · 代码编写 · 约 2 分钟

整体思路

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）

因为不能改变节点的val，只能改变节点所指向的下一个节点从而进行节点交换。

哨兵节点

因为头节点的改变需要特殊判定，逻辑复杂，所以为了保证每个要改变的节点都不是第一个，要在head前面加一个节点，即dummy head，方便函数调用。

交换next思路

设子链表为a → b → c → d，交换b, c,需要改变三处：

  • a -> next 从指向b改为指向c
  • b -> next 从指向c改为指向d
  • c -> next 从指向d改为指向b

如果用指针p遍历链表可以表示为：

//保存初始数据
ListNode *x = p -> next;
ListNode *y = p -> next -> next;
ListNode *z = p -> next -> next -> next;

//改变next
p -> next = y;
p -> next -> next = x;
p -> next -> next -> next= z;

//因为一次性交换两个节点，所以p每次跳过1个节点
p = p -> next -> next;

循环条件

因为要保证链表前最大偶数个节点交换，且不能越界访问，所以需要给while循环加上越界判定`p != nullptr && p -> next != nullptr && p -> next -> next != nullptr`

总结

本体主要实用指针遍历链表。然后通过改变next所指向的节点来来实现节点的位置交换

class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
      ListNode *dummy = new ListNode(0, head);
      ListNode *p = dummy;
      while (p != nullptr && p -> next != nullptr && p -> next -> next != nullptr) {
        ListNode *a = p -> next, *b = p -> next -> next, *c = p -> next -> next -> next;
        p -> next = b;
        p -> next -> next = a;
        p -> next -> next -> next= c;
        p = p -> next -> next;
      }
      return dummy -> next;
    }
};

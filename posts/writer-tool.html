现在加文章，只需要点一下

2026 · 10 · 22 · 约 3 分钟

每次加文章都要复制一个 HTML 文件、改标题，再手动往首页列表里插一条。做两次就烦了。

所以给博客配了个本地写作台：tools/写作台.bat，双击就能用。

怎么用

双击 写作台.bat，浏览器会弹出写作页面。左边写 Markdown，右边实时预览，看到的就是最终效果。

填好标题、日期、短名（网址里那串英文），点「发布」。剩下的自动完成：

  • 生成 posts/短名.html
  • 在首页文章列表最上面插一条
  • 提交并推送到 GitHub
  • 半分钟左右线上就能打开

为什么非要一个本地服务

GitHub Pages 是纯静态托管。浏览器里的页面没有权限往本机硬盘写文件，也没法执行 git 命令。所以「网页里点一下就直接上线」这件事，必须有本机的一个进程在旁边跑。

这个进程只监听 127.0.0.1，不开外网端口，不往外发任何数据，只做三件事：写文件、更新首页、提交推送。

代理也一并不用管了

之前 git 连 GitHub 得把代理端口写死在配置里，端口一换就静默卡住，连报错都没有，非常难受。

现在每次推送前自动探测：先读系统代理设置和环境变量，再试一批常见端口，然后真的去连一次 github.com，谁能通就用谁。一个都不通就直连。结果只作用于当次命令，不写进配置，所以换端口不用改任何东西。

能少一次手动操作，就少一个以后会忘掉的地方。
